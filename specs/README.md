## 建议开发顺序

1. R01 用户名注册：接入 Better Auth username 插件、数据库迁移、测试基建，以及注册表单和表单通用交互（校验、加载、网络异常）
2. R02 用户名登录：登录表单、统一错误提示、登录态保持、已登录访问 `/login` 跳转
3. R03 登录后首页、退出与访问控制：首页显示用户名、退出登录、未登录/会话过期跳转、受保护接口校验

三个需求共享认证配置、`/login` 页面和 Header 组件，按顺序开发，不并行。
